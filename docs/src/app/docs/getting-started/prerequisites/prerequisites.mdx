    ## Prerequisites
    This page describes the dependencies and conventions that are mandatory in order to use DevrosUI.
    Therefore it is highly advised to read through this page first and follow the steps before
    installing and using DevrosUI.

    <h3 id="dependencies">Dependencies</h3>

    <h4 id="apps">1. Next.js and React.js</h4>  

    DevrosUI is a React component library that can be used within React apps and Next.js apps.
    In order to use DevrosUI, you need to have already created your React app or Next.js app.
    You can refer to the official documentation for installing a [React app](https://react.dev/learn/installation)
    or for installing a [Next.js app](https://nextjs.org/docs/app/getting-started/installation).

    <h4 id="motion">2. Motion</h4>  

    DevrosUI also uses [Motion](https://motion.dev/) to implement animations in the components.
    Make sure to install Motion along with DevrosUI.

    <h4 id="react-icons">3. React icons</h4>  

    Some components use icons from the react-icons library so it is also necessary to install
    the react-icons library. You can do this via their official documentation site [here](https://react-icons.github.io/react-icons/).

    <h3 id="globals">Global stylesheet</h3>

    In order to give the components correct styling, you need to import the global stylesheet **once**
    in your app.  

    In ```main.jsx``` or ```App.jsx```, write the following:

    <CodeBlock
        langHighlight="jsx"
        langDisplay="JSX"
        fileName="App.jsx"
        code={`import "@devrosui/react/style.css"`}
    />

    Now you can use components in any file as shown below:

    <CodeBlock
        langHighlight="jsx"
        langDisplay="JSX"
        code={`import { Calendar } from "@devrosui/react"`}
    />

    <h3 id="themetoggle">Theme toggle</h3>

    As mentioned in the homepage, all components are compatible with dark and light modes.
    That is, the components follow a dark-theme by default, but change to a light-mode if
    the theme of the whole app also changes to light-mode. This means that you don't have to
    manually implement this for every component yourself. However, this requires you to follow
    our implementation of a theme toggle so the internal theme toggles in the components will
    be compatible with the theme toggle of your app. Our theme toggle implementation is as follows:

    <CodeBlock
        langDisplay="JSX"
        langHighlight="jsx"
        code={toggleThemeCode}
    />

    This implementation simply toggles the ```light``` className to the html document.

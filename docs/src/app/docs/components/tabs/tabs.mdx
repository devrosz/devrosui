    <h3 id="props">Props</h3>

    <h4 id="props-tabs">Tabs</h4>
    
    <div className="docs-page-table-container">
        | Prop | Type | Default | Description |
        | :--- | :--- | :------ | :---------- |
        | ```type``` | ```"local" \| "router"``` | local | type of tabs |
        | ```initialTabId``` | ```string``` | - | id of tab which should be active on first render |
        | ```styling``` | ```"primary" \| "secondary" \| "tertiary"``` | - | style type of the tabs |
        | ```children``` | ```ReactNode``` | - | Expecting ```<TabsList>``` and in case of local tabs also ```<TabRender>``` |
    </div>

    <h4 id="props-tabslist">TabsList</h4>

    <div className="docs-page-table-container">
        | Prop | Type | Default | Description |
        | :--- | :--- | :------ | :---------- |

    </div>

    <h4 id="props-tab">Tab</h4>

    <div className="docs-page-table-container">
        | Prop | Type | Default | Description |
        | :--- | :--- | :------ | :---------- |
        | ```id``` | ```string``` | - | identifies the respective tab |
        | ```disabled``` | ```boolean``` | ```false``` | Enables/disabled activation of tab |
        | ```children``` | ```ReactNode``` | - | Expecting either ```<button>``` or ```<Link>```|
    </div>

        | ```children``` | ```ReactNode``` | - | Expecting the component to render when the tab of the given id is active|
